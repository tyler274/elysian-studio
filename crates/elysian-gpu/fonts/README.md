Noto Sans (SIL Open Font License 1.1)
=====================================

`NotoSans-Regular.ttf` is a Latin-caps subset (U+0020, U+0041–U+005A) of
Google’s Noto Sans Regular, instantiated from the upstream variable font
at wght=400 / wdth=100. Full family: https://notofonts.github.io/

See `OFL.txt` in this directory. The subset is a Modified Version under
the OFL; the reserved name “Noto” is not used for a renamed family.
